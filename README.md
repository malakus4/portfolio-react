# Malakus Portfolio

Personal portfolio website built with *React,  *Vite, and *Tailwind CSS.
It showcases my project and frontend development skills.
This  project follows a clean, scalable folder structure with reusable layouts and responsive sections.

## Tech Stack
- React         
- Vite
- Tailwind
- React Router
- Lucide React

## Key Features
- Responsive Design: Fully optimized for mobile, tablet, and desktop views.
- Accessibility (A11y): Uses semantic HTML (<nav>, <ul>, <li>) and ARIA labels for screen reader support.
- Performance: Optimized images using .webp format and lazy loading.
- Modern UI: High-contrast text and intuitive layout for a better user experience.

## Deployment
- This project is configured for continuous deployment and is currently hosted on Render and Vercel.

## Getting Started
### 1. Clone the repo
- git clone https://github.com/malakus4/portfolio-react

### 2. Install dependencies
- npm install

### 3. Run development server
- npm run dev
